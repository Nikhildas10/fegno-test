## Getting Started

1. Clone the repository:
   git clone <repository-url>

2. Install dependencies:
   pnpm install

3. Set up environment variables:

   - Copy `.env.example` to `.env`
   - Update the variables as needed

4. Start the project:
   pnpm run dev
